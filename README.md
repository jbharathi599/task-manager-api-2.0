# Task Manager API 2.0

A full-stack task management application with a modern dashboard, built step by step as a portfolio project.

> **Status:** In development. Features are added and checked one at a time, and this README only lists what has actually been built and verified.

## Planned Tech Stack

**Backend:** Java 21, Spring Boot, Maven, Spring Security with JWT, PostgreSQL, Flyway, Bean Validation, Swagger/OpenAPI, JUnit 5, Mockito

**Frontend:** React, Vite, JavaScript, Ant Design, React Router, Axios

**DevOps:** Git, GitHub, Docker, Docker Compose, GitHub Actions, Kubernetes

## Planned Features

- User registration and login with JWT authentication
- ADMIN and USER roles
- Projects with members, and tasks with status, priority, due date, and assignee
- Comments on tasks
- Search, filtering, sorting, and server-side pagination
- Table view and Kanban board
- Dashboard statistics and an admin user management page
